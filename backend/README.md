# VisitorPortal Backend

This directory contains the Laravel backend for VisitorPortal.

Use the repository-level README and docs for setup and operations:

- `../README.md`
- `../docs/setup.md`
- `../docs/deployment.md`
- `../docs/configuration.md`

Production bootstrap commands:

```bash
php artisan visitorportal:install
php artisan visitorportal:create-admin
php artisan visitorportal:sync-permissions
```
